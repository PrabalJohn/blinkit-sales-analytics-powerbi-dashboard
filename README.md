# blinkit-sales-analytics-powerbi-dashboard
An interactive Power BI dashboard developed to explore Blinkit grocery sales performance across product categories and outlet characteristics. The report includes sales KPIs and breakdowns by item type, fat content, outlet location, outlet size, outlet type, and outlet establishment year.

# Objectives
- Monitor key sales and product metrics.
- Compare sales across grocery item categories.
- Explore sales distribution by outlet location tier, size, and type.
- Examine sales in relation to outlet establishment year.
- Enable interactive exploration using report filters and a metric selector.

# Tools & Skills
- Microsoft Power BI Desktop
- Power Query (data cleaning and transformation using the visual editor)
- Power BI KPI measure creation (using the visual interface)
- Data visualization and interactive reporting

# Data Preparation
Performed limited data cleaning and transformation in Power Query using its visual editor. The dashboard's KPI measures were created through Power BI's interface. 
Dashboard Metrics

# The report includes the following KPI measures:
- Total Sales
- Average Sales
- Number of Items
- Average Rating

# Dashboard Components

# Visual / Analysis	Purpose
Sales by Item Type:	Compare sales across grocery product categories.
Fat Content by Outlet Location:	Examine fat-content categories across outlet location tiers.
Sales by Outlet Establishment Year:	Explore sales in relation to outlet establishment year.
Sales by Outlet Location:	Compare sales across outlet location tiers.
Sales by Outlet Size:	Understand the sales distribution by outlet size.
Fat Content:	Compare sales contribution across fat-content categories.
Outlet Type KPIs:	Compare outlet types using sales, number of items, average sales, and average rating.
KPI Cards:	Provide a quick overview of key metrics.

# Interactive Features
- Filters for outlet location type, outlet size, and item type.
- A metric selector to switch the metric being explored in supported visuals.
- Interactive report visuals for exploring and comparing selected data.
